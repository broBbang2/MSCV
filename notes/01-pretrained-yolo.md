# 1단계: 사전학습 YOLO 관찰 기록

## 해볼 것
1. 책상 위 물건(컵, 폰, 키보드)을 비춰보고 잘 잡히는지 보기
2. 아이폰을 들고 걸어다니며 비춰보기 → 움직일 때 박스가 흔들리거나 사라지는지
3. `--conf 0.05`, `--conf 0.6`으로 바꿔가며 박스 개수가 어떻게 변하는지
4. 화면의 FPS 확인 (`yolo11n.pt` vs `yolo11s.pt`)

## 답해볼 질문
- 사전학습 YOLO가 못 찾는 일상 사물은 무엇이고 왜일까? (힌트: COCO 데이터셋 80개 클래스 목록)
- confidence 임계값을 낮추면 얻는 것과 잃는 것은?
- 모델이 커지면 FPS와 정확도가 어떻게 바뀌나?

## 관찰
- 맥 내장 카메라(0번, 1920x1080), MPS에서 한 프레임 추론 약 70ms (n, s 비슷)
- `yolo11n`이 마우스를 `cell phone`으로 인식함. COCO에 `mouse` 클래스가 있는데도 틀림
  → 위에서 내려다본 마우스는 "어둡고 둥근 직사각형"이라 폰과 모양이 비슷하고,
    nano 모델은 그 차이를 구분할 만큼 크지 않다
